# Registro de Incidencias

## Instrucciones
Registrar cada error encontrado durante el desarrollo y las pruebas.
Seguir el procedimiento: Reproducir → Registrar → Revisar consola → Identificar causa → Corregir → Volver a probar → Cerrar.

## Problemas Comunes a Verificar

| # | Problema | Causa posible | Solución |
|---|----------|--------------|----------|
| 1 | 404 o página no encontrada | Ruta incorrecta | Verificar ruta del archivo |
| 2 | Cámara bloqueada | Sin HTTPS | Usar URL HTTPS de Codespaces |
| 3 | Falta de HTTPS | Abrir con HTTP | Verificar URL de Codespaces |
| 4 | Marcador no detectado | Iluminación / tamaño | Imprimir >8cm, buena luz |
| 5 | Modelo fuera de vista | Escala incorrecta | Ajustar scale del objeto |
| 6 | Modelo demasiado grande | Escala > 1 | Reducir scale (0.2-0.5) |
| 7 | Scripts no cargados | Orden incorrecto | Cargar A-Frame antes de AR.js |
| 8 | `AFRAME is not defined` | Script carga antes de A-Frame | Mover script después de aframe.min.js |
| 9 | URL del Codespace inactiva | Codespace detenido | Reiniciar Codespace |
| 10 | Recursos muy pesados | Archivos grandes | Comprimir modelos y multimedia |
